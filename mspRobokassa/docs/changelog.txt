Changelog for Robokassa.

2.2.3
==============
- В подпись Result URL для /InvoiceServiceWebApi/api/CreateInvoice добавлен параметр shp_interface=InvoiceService.WebApi

2.2.2
==============
- Убраны публичные значения по умолчанию для учётных данных Robokassa и добавлена проверка конфигурации перед созданием платежа и обработкой ResultURL
- Логирование ошибок ResultURL ограничено безопасным набором диагностических параметров
- В документации URL для Robokassa переведены на HTTPS и добавлено требование действительного TLS-сертификата

2.2.1
==============
- Установка через браузер доступна только авторизованному пользователю Manager с правом управления пакетами; прямой HTTP-доступ к скриптам _build запрещён

2.2.0
==============
- Для РФ сегмента устаревший cURL-запрос заменён на JWT Invoice API Robokassa
- Для Казахстана сохранён прежний cURL-механизм оплаты

2.1.2
==============
- Добавлена передача email покупателя на платежную страницу
- Для Success Url добавлена возможность работы методом GET

2.1.1
==============
- Убран неиспользуемый параметр OutSumCurrency

2.1.0
==============
- Предусмотрен вариант расчета чека, при отрицательной стоимости (скидке) записанной в поле msPayment.price

2.0.0
==============
- Минимальная версия PHP повышена до 7.0
- Весь код отрефакторен по стандарту PSR-12
- Реализована отправка корзины

1.0.0
==============
- Initial release.
